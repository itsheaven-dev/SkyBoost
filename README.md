## 📌 Overview

**SkyBoost** is a web panel template designed for social media boosting services (Kick, Twitch, Telegram). This repository contains **only the client-side (frontend)** files, including user authentication forms, platform dashboards, and administration layouts.

> ⚠️ **Note on Layout/Design:** The project layout is currently work-in-progress. Some styles and UI elements may appear slightly misaligned or broken, requiring minor CSS fixes.
